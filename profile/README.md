# 🏛️ Universidad Ricardo Palma - Organización Oficial de GitHub

Bienvenido al espacio oficial de código y desarrollo de la **Universidad Ricardo Palma**. 

Esta organización es administrada por el **Equipo de Infraestructura y Cloud**, con el objetivo de centralizar, gestionar y modernizar los recursos tecnológicos de nuestra institución académica.

## 🚀 Nuestros Objetivos
* **Modernización de Infraestructura:** Migración y gestión de servidores académicos e institucionales.
* **Ciencia de Datos e IA:** Espacio colaborativo para el desarrollo de modelos predictivos y Data Lakehouses de nuestros programas de maestría.
* **Integración Continua:** Implementación de flujos CI/CD para plataformas como Moodle y sistemas de gestión interna.
